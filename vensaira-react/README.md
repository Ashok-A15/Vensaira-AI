# VENSAIRA AI — React Application

Enterprise AI Solutions, Software Engineering, Industry Transformation, and AI-Powered eLearning Platform.

Built with **React 19**, **Vite 8**, and **React Router 7**.

---

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

---

## 🛠️ Tech Stack

- **Framework:** React 19 (`react`, `react-dom`)
- **Build Tool:** Vite 8 (`@vitejs/plugin-react`)
- **Router:** React Router 7 (`react-router-dom`)
- **Styling:** Vanilla CSS with custom design tokens
- **Animations:** Canvas 2D neural network particle animation
- **Inquiries:** Formspree API integration

For full application architecture, routing guide, and feature documentation, see the root [`README.md`](../README.md).
