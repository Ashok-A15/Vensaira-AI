# VENSAIRA AI - Corporate Website

Client-facing corporate landing page and website for **VENSAIRA AI** — Autonomous AI Verification Platform for High-Stakes Enterprise Systems.

---

## Overview

This repository contains the standalone, production-ready corporate website for VENSAIRA AI. It is built purely with clean, modern HTML5, CSS3, and JavaScript, requiring zero external server-side runtimes or databases.

---

## Website Structure

```
VENSAIRA AI/
├── index.html              # Main corporate landing page
├── contact.html            # Contact & inquiry page
├── mission-vision.html     # Mission, Vision & Core Values page
├── styles.css              # Global responsive stylesheet & design system
├── main.js                 # Interactive navigation, animations & UI logic
├── assets/                 # Brand assets, vectors, and logos
│   ├── logo.svg
│   ├── logo.png
│   └── logo-full.png
├── .gitignore              # Git ignore rules
└── README.md               # Repository documentation
```

---

## Key Features

- **Autonomous AI Verification Platform Showcase:** Solutions, Platform architecture, Customer stories, Resources, and Company sections.
- **Modern Cyber Aesthetics:** Ambient glowing light effects, glassmorphic UI cards, cyber-grid backgrounds, and responsive typography.
- **Multi-page Architecture:**
  - `index.html` — Homepage showcasing enterprise AI solutions and capabilities.
  - `contact.html` — Enterprise contact and consultation inquiry form.
  - `mission-vision.html` — Six core corporate values, mission, and long-term vision.
- **Fast & Lightweight:** Pure client-side static application. No backend or database server required.

---

## How to Run Locally

Open `index.html` directly in any modern browser, or run a local static server:

```bash
# Using VS Code Live Server extension, or:
npx serve .
```
